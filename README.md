# Steven Ng — Event Production & AV Portfolio

Static portfolio site: 42 photos and 4 videos of event production work
(OBS live streaming, Allen & Heath SQ-5, Q-SYS/Dante AV, ballroom and
outdoor events), plus a profile photo and Dante Level 1 certification note.

## Deploy

- Cloudflare Pages: create a project from this repo, or drag this folder
  into a Pages direct upload. Build command: none. Output directory: `/`.
- The live page is `index.html`; media lives in `assets/`.
